# 调度中心

调度中心 `/schedule` 是模型查看与调度操作的统一入口。选择对外模型后，管理员可以查看跨分组的候选上游、状态、近期调用表现，并调整优先级、权重、启停、测活与恢复。当前占比是调度配置计算的结果，实际请求表现以调用统计和请求日志为准。

候选的价格入口打开上游价格详情，保留基础价格、档位价格及已有 Fast 模式价格的编辑和重置。价格按渠道与上游模型共享，保存前可查看完整关联关系和受影响分组。详情中的目录同步作用于全局模型目录和自动价格；自动定价仍继续工作。

访问密钥登录的用户在同一入口只查看其授权范围内的模型、协议和参考价格，不显示内部调度候选与管理操作。参考价格单位为 USD / 百万 Tokens，用于费用估算，不等同于实际供应商账单。

独立 `/models` 页面已移除。分组详情的模型标签继续负责该分组的模型结构与别名配置；调度中心负责跨分组调度和共享价格。目录规格与独立模型关系树不再占用调度界面。
