# UI 开发检查清单

根据当前讨论整理；后续讨论确认的新关注点继续补充。

- [ ] 同一视口中，页面名称不重复显示；窄屏仍能识别当前页面。
- [ ] 同一状态下，同一操作和同一统计值不重复呈现；优先保留位置明确、有上下文的入口或数字。
- [ ] 删除重复展示的筛选值，以及解释界面布局或显而易见操作的文字；优先让布局和控件表达含义。
- [ ] 控件用途已明确时，不单独占行显示标签；仍须保留无障碍名称和必要的字段区分。
- [ ] 默认单页、无筛选时，避免重复显示结果总数；筛选或分页后保留有意义的结果数量。
- [ ] 避免单个操作独占一行；优先与相关筛选或内容并排，窄屏自然换行。
- [ ] 删除前确认含义：启用开关与可用状态、总数与筛选结果数不一定相同；空状态可保留必要引导。
- [ ] 不因精简而删除必要的状态、错误、风险、字段约束或操作反馈。
- [ ] 同类问题检查其他页面，并兼顾桌面、窄屏和无障碍语义。
