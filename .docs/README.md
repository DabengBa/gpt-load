# GPT-Load Documentation

GPT-Load is an API gateway and management interface for configuring provider
credentials and model routes. The current management frontend is Astryx.

Start with the [semantic product documentation](db/pages/dispatch-center.md)
for Dispatch Center behavior, the [technical documentation](tech/) for
implementation and operations, and the [architecture decisions](adr/) for
recorded trade-offs. [Documentation maintenance rules](AGENTS.md) describe
ownership and validation. [Project history](PROJECT_HISTORY.md) records
selected shipped architectural changes.
